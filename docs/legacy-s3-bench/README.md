# Legacy bench diary (ESP32-S3 DevKitC-1)

The bench status and log the original guide kept for its ESP32-S3 DevKitC-1 (N16R8, FTDI
adapter on a Mac): 49 commands, from installing PlatformIO to flashing every S3 lab. They describe
that board, not the UNIT Pulsar C5, so they no longer ship in `public/data/`. They stay here as a
record of how the S3 labs were brought up.
