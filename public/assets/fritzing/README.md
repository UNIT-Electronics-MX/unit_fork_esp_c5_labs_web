# Fritzing reference artwork

This directory contains two third-party breadboard SVGs, copied without visual changes and renamed for local use. The P3 potentiometer wiring figure and these graphics are available under [Creative Commons Attribution-ShareAlike 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/). The rest of the application retains its own license.

| `adafruit_1.9in_320x170_tft.svg` | [Adafruit 1.9-inch TFT part](https://github.com/adafruit/Fritzing-Library/blob/master/parts/Adafruit%201.9in%20320x170%20TFT.fzpz), breadboard SVG extracted from the `.fzpz` archive | Adafruit |

The Adafruit breakout drawing is an identification reference. Its 11-pin connector differs from the eight-wire display module in lesson 03, so the two wiring tables must not be treated as interchangeable.
